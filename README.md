# 퍼스널 버닝 플래너

본섭 퍼스널 버닝(9/17~11/18)의 성장 미션, 플레임, 교환권, 보스 미션과 모멘텀 패스 PLUS(~10/21)를 한 타임라인에 올려 **11월 18일 마감 위치**와 **단계별 도달일**을 계산하는 사이트입니다.

이전 이름은 285 플래너입니다. 챌린저스 월드가 9/16에 끝나면서 챌섭 계산기와 버닝 비욘드(260→280) 계산은 지웠습니다. 이전 작업 기록은 저장소에 올리지 않고 로컬 `archive/`에 보관합니다.

## 화면

| 탭 | 내용 |
|---|---|
| 퍼스널 버닝 | 입력(내 캐릭터, 성장 미션, 플레임, 보스 미션, 일과, PLUS·보유 아이템)과 결과(마감 위치, 통과 단계, 도달일, 시점 비교, 주차별 진행, 단계표, 경험치 출처) |
| 아이템 환산 | 보유한 크림슨·메카베리·블루베리·사우나·비약·상급 EXP를 선택 레벨부터 전부 쓰면 어디까지 오르는지 |
| 보상표·자료 | PLUS 레벨별 보상, 퍼스널 규칙·코인샵, 레벨별 플레임·교환권 값, 퍼스널 보스 35개 표 |

입력은 이 브라우저의 `localStorage`(`maple-personal-planner-v2`)에 저장합니다. 저장소를 못 쓰는 환경에서도 계산은 됩니다.

## 계산 방식

- **일 단위 시간축** 하나에 날짜가 정해진 이벤트를 올립니다. 매주 목요일 0시에 플레임 +24,000(보유 36,000 상한), 보스 초기화, 주간 컨텐츠, PLUS 주간 해금이 일어납니다.
- **성장 미션 단계표**: 한 레벨 안에서 단계 간격은 일정하고, 단계 보상은 그 레벨의 몬스터 기본 경험치 × 502,828.8입니다(본섭 286~289레벨 화면 네 값과 일치). 미션 화면의 「다음 단계 목표」를 넣으면 나머지 단계를 이어 만듭니다. 본섭 두 캐릭터(286·287레벨 지정)의 30단계 목표를 0.01%p 안쪽으로 재현합니다. 285 미만과 290 이상의 간격은 9/11 테섭 표본과 커뮤니티 계산에서 구한 추정입니다.
- **플레임** 1마리 = 사냥터 몬스터 기본 경험치(하루1소재 표) × 72. ×72는 본섭 9/23 플레임 로그 3건과 정확히 맞는 값이고 하루1소재에 플레임 계산식은 없습니다. **교환권** 1장 = 내 레벨의 몬스터 기본 경험치 × 480으로, 하루1소재·메이플로드 교환권 표와 260~299레벨 전부 같습니다.
- **보스 미션** 한 번 = 하루1소재 보스 표 값 × 10,000 ÷ 파티원 수(레벨과 무관). 「보스 상한」 프리셋은 선택한 보스 이하에서 보스마다 가장 센 난이도를 경험치 순으로 최대 12개 담습니다.
- **일과**: 몬스터파크 1판 × (1 + 썬데이 0.5 + 추가 경험치 %). 추가 경험치는 아르고호의 가호 전술 마법(하루1소재의 「보약」)이고 익스트림 몬스터파크에도 붙습니다. 에픽 던전은 289레벨까지 악몽선경, 290레벨부터 아우룸 레기스이며 보상 배수 5(흔히 4배 = 기본 + 400%)가 기본입니다.
- **사냥**: 30분 = 7.5초 리젠 240번 × 40마리 × 몬스터 기본 경험치 × 레벨 차 보정(하루1소재 식)에 입력한 추가 경험치 합계 %를 곱합니다. 기본은 주 4시간, +300%입니다.
- **모멘텀 패스 PLUS**: 공식 813 표의 크림슨·상급 EXP·VIP 사우나·VIP 부스터·경험치 4배 쿠폰을 계산합니다. 부스터(1개 = 1,710마리에 기본 경험치 10배)와 4배 쿠폰(30분, 순수 사냥 경험치의 3배 추가)은 사냥하는 동안에만 쓰입니다.
- **시점 비교**: 크림슨 사용 시점(즉시 / 285·290·295까지 모음 / 10/21까지 모음) × 교환권 사용 시점(즉시 / 마감 직전)을 모두 돌려 통과 단계, 마감 위치 순으로 고릅니다. PLUS 등급 비교와 지정 시점 비교도 같은 방식입니다.
- 계산 엔진은 `lib/main-planner.mjs`(순수 함수), 경험치 표는 `lib/exp-tables.ts`, 하루1소재 표는 `lib/personal-data.mjs`입니다.

## 근거와 한계

- 일정·규칙: 넥슨 공식 업데이트 [813](https://maplestory.nexon.com/news/update/813)(9/24 수정본까지)
- 몬스터 기본 경험치·교환권·보스 표·사냥터: [하루1소재](https://haru1sojae.kr/table) (2026-10-04에 번들 상수표를 읽어 옮김)
- 몬스터파크·그란디스·익몬·에픽 던전(악몽선경 289까지, 아우룸 레기스 290부터)·농장 표: 하루1소재, [메이플로드](https://mapleroad.kr/utils/exp_calculator)
- 보스 경험치는 공식 공지에 수치가 없습니다. 하루1소재 표 35개 중 5개(세렌 노멀·하드, 칼로스 이지, 대적자 이지, 카링 이지)는 본섭 9/27 보스 미션 화면과 정확히 같고 나머지 30개는 화면 대조 전입니다.
- 몬스터파크·그란디스 일퀘에는 아르고호의 가호(전술 마법, 기본 몬파 +50%·그란디스 +10%, 입력으로 변경)를 곱합니다.
- 일과 경험치(몬파·그란디스·주간 컨텐츠) 표는 챌섭에서 검증한 값을 그대로 쓰며 본섭 실측이 아닙니다. 「하루 일과 직접 입력」(몬파·그란디스)과 「주간 컨텐츠 직접 입력」(익몬·악몽선경)으로 각각 덮을 수 있습니다.
- 모멘텀 PLUS는 시작부터 주 2,500포인트를 모두 채웠다고 보고 해금된 보상을 바로 받는 것으로 계산합니다. 기본값은 프라임 구매에 수령 0(열린 보상을 모아 둔 상태)입니다. 10/22·11/19 새벽 사용 시간은 뺐습니다.
- 계산 결과는 커뮤니티의 296레벨 계산(몬파·익스트림·에픽 던전·일퀘·단계 보상)과 같은 식으로 맞춰 봤습니다. 대조 기록은 저장소 밖 작업 문서에 있습니다.
- 296레벨에 닿으면 계산을 멈춥니다(필요 경험치 표가 295까지).

## 실행과 검증

```bash
pnpm install
pnpm dev          # 개발 서버
pnpm test         # 빌드 후 tests/ 전체 (표, 엔진, 화면)
pnpm lint
```

배포는 `.github/workflows/pages.yml`이 `GITHUB_PAGES=true pnpm run build`로 GitHub Pages에 올립니다.
