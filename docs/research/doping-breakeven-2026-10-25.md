## 도핑 항목과 합산 규칙

원문 `eY/U`는 사냥 기본량에 `0.5/0.7`, `2/3`, `0.1/0.2`, `1`, `0.1/0.15`, `0.3`을 곱해 **각 도핑으로 추가되는 EXP**를 구한다. 전체 증가 배수는 `I(e)`의 `1+합계/100`이다. 쿠폰을 다른 모든 도핑에 다시 곱하는 방식이 아니다. 예를 들어 3배(+200)+고농축비(+20)+펜던트(+30)=추가 250%, 총 3.5배다.

|---|---|---|
| 경험치 쿠폰 | 3배 +200%, 4배 +300% (`U`) | 한 항목 선택 |
| 추가 경험치 버프 | +50%, +70% (`U`) | 한 항목 선택 |

## 가격선과 갈림길

가격선 = 돋보기 EXP / 기준 상품 추가 EXP × 기준 상품 순비용. 수상한은 도핑에 비례해 가격선이 올라가고, 탐정은 고정된다. VIP는 수상한과 EXP가 같지만 구매할 수 없어 메소 효율의 구매 순위에 넣지 않고 보유분 우선 사용으로 표시한다.

수상한 손익분기 추가% = `(현재 시세 × 에픽 추가 EXP / (수상한 순수 EXP × 에픽 순비용) − 1) ×100`. 정확한 경계에서는 같은 비용이고, 이를 초과하면 수상한이 더 저렴하다. UI는 약 소수 둘째 자리로 표시한다. 기준 비용이 0 이하이면 양수 가격 돋보기의 갈림길을 표시하지 않는다. 시세 빈칸은 미입력, 명시한 0은 무료 보유/획득으로 구별한다.

캐릭터와 몬스터 레벨을 같게 둔 재현값([입력·전 결과 JSON](doping-breakeven-cases-2026-10-25.json)):

| 기준 | 레벨 | 에픽 1단계 갈림길 추가% | 에픽 1→2단계 갈림길 |
|---|---:|---:|---:|
| 원 요청: 2,300 메포·수상한 210만 | 285 | 243.75577228605% | 0%부터 수상한이 저렴 |
| 원 요청: 2,300 메포·수상한 210만 | 290 | 302.10172422850% | 10.41929892347% |
| 최종 기본: 2,150 메포·수상한 205만 | 285 | 205.49068729246% | 0%부터 수상한이 저렴 |
| 최종 기본: 2,150 메포·수상한 205만 | 290 | 259.40889733488% | 0.18489314089% |

탐정 시세 1억은 도핑과 무관하게 위 두 레벨 모두 에픽 1단계보다 비싸고, 에픽 1→2단계보다 저렴하다. 최종 기본값의 탐정 가격선은 285레벨 약 5,368.41만/20,125.88만, 290레벨 약 4,563.05만/16,369.73만 메소(각 1단계/1→2단계)다.

## 화면과 공유 입력

상단 결론 카드 → 캐릭터·도핑·시세 접기 → 구매 가능한 상품의 가로 막대 → 구매 불가 상품 접기 → 돋보기 2종/VIP 가격선 카드 → 도핑 슬라이더와 접는 기준표 → 접는 주의사항 순서다. 가격 입력은 만 메소 단위이며 원 단위 9자리 숫자를 나열하지 않는다. 입력을 바꾸면 즉시 판정과 막대·가격선이 갱신된다. 폼 입력은 잘못 넣은 값과 일시적 빈칸도 표시하며 유효한 입력만 저장한다.

메포 시세는 `input.market.maplePoints` 한 곳에 저장한다. 효율 비교와 퍼스널 플래너 일과 입력에서 같은 값을 읽고 바꾼다. 에픽 주간 비용의 메소 환산도 동일한 `maplePointMeso`를 사용한다. 플래너에는 총 메포 지출의 수수료 포함 메소액(주화 판매 전)을 표시하고, 구매 비교는 단계별 주화 판매액을 차감하므로 두 표시의 의미를 구별한다.

도핑 숫자와 도우미는 `input.efficiency.{bonus,doping}`에 **비교 전용**으로 저장한다. 처음에는 플래너 사냥 추가%를 가져오고, 「플래너 값으로 맞추기」로 다시 가져온다. 비교용 3배·4배 쿠폰·일시 버프를 기간 전체 사냥에 넣지 않으므로, 별도로 가진 4배 쿠폰 재고와 중복 가산하지 않는다. Claude의 독립 검토(137744)에서 발견한 중복 경로를 이 방식으로 제거했다. 기존 플래너 추가%를 직접 입력할 때도 보유 보상으로 입력한 4배 쿠폰을 빼도록 안내한다.

입력 중 빈칸·소수점은 변경 전 기준값과 함께 보존한다. 공통 메포 값이 플래너에서 바뀌면 오래된 입력 문자열을 무시한다. 실제 화면에서 효율 2,300 → 플래너 2,300 → 플래너 2,150 → 효율 2,150과, 비교용 4배 선택 시 비교 600% / 플래너 300% 유지·저장·맞추기 후 300% 복원을 확인했다. 회귀 검사는 비교용 3배·4배를 바꿔도 기간 전체 출처별 EXP와 보유 4배 쿠폰 사용량이 바뀌지 않음을 확인한다.
