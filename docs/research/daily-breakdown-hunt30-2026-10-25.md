## 최종 지시와 계산 변화

대표 보충: “연결하면됨. 일퀘때문에 1만마리가 찬다고 해도 무방함”. 따라서 8893498의 부족분 사냥 보충을 제거했다. 선택 켬은 10/22~11/18 사냥+일퀘로 수집 미션을 채운다고 보고 무료 탐정을 매일 1개 쓴다. 사냥 0회여도 이 가정을 적용한다. 선택 끔은 사냥량·옛 detectiveFree 체크와 무관하게 무료 0개다. 오늘 일과 완료·300 상한·이벤트 기간·구매 합계 하루 3개 한도는 기존대로 적용한다. 그란디스 EXP 체크는 해당 보상 포함 여부이며 수집 미션 가정과 독립이다.

일반 사냥은 입력한 시간의 경험치만 넣는다. 새 기본값은 하루 30분 × 1회(주 3.5시간). 화면은 하루 횟수를 입력받고 내부 저장 필드 huntHoursPerWeek를 유지해 옛 주간 시간 ÷ 7 ÷ 0.5를 손실 없이 표시한다. 변경 시 하루 횟수 × 7 × 0.5로 저장한다. 사냥 추가 경험치 또는 기존 30분 실측 입력을 그대로 사용한다. 실측 EXP에는 추가%를 재적용하지 않는다. 쿠폰은 30분 세션 수, 부스터는 같은 시간 내 100초 사용 여지로 계산하며 무료 돋보기 가정으로 사용 여지를 늘리지 않는다.

저장 호환: 명시한 dailyTenThousand 켬/끔과 주간 시간은 보존한다. 항목이 없던 옛 저장은 옛 detectiveFree 및 일반 사냥 1만 마리 충족 판정을 새 선택으로 옮긴다. 예: 주 2시간은 끔, 주 4시간은 켬. 주간 시간도 없던 옛 저장은 당시 기본 4시간을 보존한다. 8893498 이후 켬으로 저장된 입력의 부족분 보충은 최종 지시대로 제거되므로 결과가 바뀐다. 아래 주 2시간 사례와 테스트가 이 변화를 명시한다.

## 이전 화면 이력과 복원 방식

- a6b0999: 계산 근거별 기여 EXP와 표시 반올림 잔여 배분을 확인했다.
- a136566: 계산 근거 원천별 제외 기능의 데이터 연결을 확인했다. 이번 요청은 근거 표시 복원이며, 별도 제외 기능은 추가하지 않았다.
- 76ce3c9 이전 챌섭 날짜별 표의 날짜·출처·마감 위치 형태를 확인했다. 과거 시즌 값은 복사하지 않고 현재 applyUnits/addSource의 실제 적용 EXP를 사용한다.

현재 엔진의 addSource에서 날짜별 sourceRaw를 함께 기록한다. 각 날짜는 totalRaw, 끝 레벨·%, 통과 단계도 내보낸다. 전 출처를 순회하므로 사냥·몬파·일퀘·익몬·에픽·보스·플레임·단계 보상·무료/구매 탐정·수상한 돋보기·쿠폰·부스터·아이템·출석·사과 보상이 빠지지 않는다. 새 출처 ID도 이름 매핑이 없으면 ID 그대로 보인다. 한 번도 얻지 않은 출처의 0 열은 만들지 않는다.

결과는 경험치 내역 탭을 기본으로 연다. 위에 출처별 기간 합계, 아래에는 7일씩 접는 날짜별 표를 둔다. 첫 주만 기본 펼침, 모바일은 날짜별 카드 형태다. 기간 전체의 정수 EXP를 출처별로 반올림한 뒤 잔여를 날짜에 배분한다. 따라서 일별 출처 합계=일 합계, 일 합계 누적=주 합계=기간 합계, 날짜별 각 출처 누적=출처별 기간 합계가 정확히 맞는다. 원본 실수 EXP는 수정하지 않는다. 개별 표시 기여의 조정은 1 EXP 미만이다. 레벨% 환산과 원본 실수 합산은 부동소수점 오차 2 EXP 미만으로 검증한다.
