# 출석 보상과 평소 사냥 계산 — 2026-10-09

구현 전 기준: `0b18989`. 수정·로컬 커밋만 하며 push·게시·댓글·외부로 저장소 내용 전송은 하지 않는다.

## 보상 근거와 기한

[공식 업데이트 813](https://maplestory.nexon.com/News/Update/813)의 「프로텍트 아르고」 표와 유의사항을 직접 읽었다. 비행 의자를 제외한 모든 출석 보상은 11/18 23:59 수령, **11/19 02:00 사용 마감**이다. 일 단위 계산은 11/18까지 포함한다. PLUS의 10/22 02:00 마감(계산 10/21)과 별도로 센다.

| 40일 전체 보상 | 수량 | 지급 일차 |
|---|---:|---|
| 성장의 비약 200~269 | 1 | 20 |
| 성장의 비약 200~279 | 1 | 40 |
| 상급 EXP 교환권 | 6,000 | 11·21·31, 각 2,000 |
| VIP 부스터 | 40 | 6·16·26·36, 각 10 |
| VIP 사우나 | 4시간 | 2·7·12·17·22·27·32·37, 각 0.5시간 |

새 `attendance` 입력은 기준일에 이미 보유한 남은 수량이다. 비약·EXP·사우나는 기준일부터 사용하고 부스터는 사냥할 때 쓴다. 전체 수량 버튼은 값을 더하지 않고 덮어쓴다. 아직 받을 보상을 날짜별로 나눠 지급하는 기능은 없으므로, 버튼 사용 뒤 실제 남은 수량으로 맞추라는 안내를 붙였다. 명의 내 지정 메이플ID의 보상을 다른 계정에도 중복 넣으면 안 된다.

[메이플로드 비약 계산기](https://mapleroad.kr/utils/elixir)의 공개 효율 표를 읽었다. 269용은 Lv.269까지 100%, Lv.286 2.227%, Lv.288 1.841%; 279용은 Lv.279까지 100%, Lv.286 15.217%, Lv.288 12.576%다. 범위를 넘으면 각각 마지막 레벨 필요 경험치 **2,438,047,518,853 / 16,657,228,589,191** EXP로 재현된다. 기존 279용의 `Lv.280 필요 경험치 × 0.49505` 근삿값을 정확한 정수로 바꿨다. [별도 공개 계산기](https://maple-to-do.com/utils)의 고정 경험치 표시도 같은 두 정수다. 공식 813에는 비약 경험치 식이 없으며, 읽은 하루1소재 청크에서 비약 식은 찾지 못했다.

## 저장 호환

저장 키·버전은 v2를 유지한다. 새 항목은 0, 평소 사냥터는 플레임과 같게, 실측은 0으로 복구한다. `items`의 옛 상급 EXP·사우나·부스터는 출처를 알 수 없어 기존 PLUS 기한을 유지하며 `attendance`에 복제하지 않는다. 출석분이었다면 사용자가 옮겨야 한다. PLUS가 주지 않는 옛 `items.potion279`는 새 출석·보유 칸으로 한 번 옮긴다. 재저장·재로딩 시 다시 더하지 않는다.

PLUS의 `claimedLevel` 의미와 저장 구조는 유지했다. 입력한 레벨까지의 보상을 자동 지급에서 빼고 남은 아이템을 직접 입력하는 값이다. 0은 열린 보상을 전부 자동으로 더한다. 10으로 넣고 남은 수량을 적으면 이미 일부 사용한 경우도 표현할 수 있다.

## 사냥

플레임 사냥터와 평소 사냥터를 별도로 계산한다. 평소 사냥터는 플레임과 같게 / 내 레벨 몬스터 / 고정 레벨 중 선택하며, 일반 사냥·4배 쿠폰·부스터는 모두 평소 사냥터를 쓴다. 레벨업·미션 보상 경계에서 남은 시간을 새 값으로 계산하는 규칙은 유지했다.

Lv.292, 주 4시간, 추가 경험치 +300%에서 일반 사냥은 293 몬스터 **1,831,763,681,280** EXP, 294 몬스터 **1,697,538,078,720** EXP다. 플레임을 294에서 잡고 평소 사냥만 293으로 바꿀 수 있다. 사냥·플레임 둘 다 293으로 바꾸는 이전 반례도 294 대비 약 **0.01124%p/주** 더 얻는 것으로 재현했다.

30분 실측값을 넣으면 일반 사냥에 마릿수·버프를 다시 곱하지 않는다. 레벨업 뒤에도 입력한 30분 값을 유지한다. 실측에서 별도 계산할 4배 쿠폰·부스터는 빼야 한다. 그 추가분과 하루 사용 가능 부스터 수는 여전히 선택 몬스터와 30분 9,600마리 기준 추정이다. 두 재고의 부스터는 같은 사냥량에 중복 적용하지 않고 먼저 사라지는 PLUS분부터 쓴다.

## 미확인과 화면 확인 위치

탈라하트 일퀘 정수는 변경하지 않았다. 읽은 [하루1소재 청크](https://haru1sojae.kr/_next/static/chunks/3pbsp2-ukxvfz.js)에는 몬스터·몬파·에픽 등이 있지만 해당 일퀘 정수를 찾지 못했다. [메이플로드](https://mapleroad.kr/utils/exp_calculator)의 공개 GET API는 레벨 290에서 탈라하트를 0.0305%로 반환해 89,700,000,000과 89,730,912,960을 구분할 수 없다.

Claude가 눈으로 확인할 위치:

1. PLUS 바로 아래 접힌 「남은 출석·보유 보상」, 전체 수량 버튼과 이 캐릭터만 넣으라는 안내.
2. 일과·사냥 안의 평소 사냥터 선택, 직접 레벨, 접힌 30분 실측 입력.
3. PLUS 레벨 설명과 보유량 입력의 긴 안내가 모바일에서 잘 읽히는지.
4. 결과 카드의 앞으로 받을 코인·조각, 배분·주차만 펼친 나머지 결과 묶음.
5. 390px 화면의 결과 띠·표 가로 스크롤·접기 버튼과 아이템 환산 탭의 두 비약.

빌드 후 실제 SSR에서 접힌 상태·요약·입력 연결을 검사한다. 도구 브라우저 연결 실패로 실제 클릭과 모바일 시각 검사는 별도 확인이 필요하다.
